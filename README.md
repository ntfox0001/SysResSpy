# SysResSpy · 系统进程资源监控

一个**低系统占用**的 Windows 进程资源监测工具，用于实时查看系统各进程的 CPU / 内存占用，并绘制**从软件启动以来**的占用历史曲线。

- 使用 C# 编写
- 当前界面基于 **WinUI 3（Windows App SDK）** 构建（现代 Fluent 风格，支持深浅色主题自动切换）
- 采样核心独立于界面层，可跨 UI 框架复用（项目同时保留了 WinForms 采样引擎）

---

## 功能特性

### 进程列表
- 实时显示各进程的 **名称 / PID / CPU% / 内存**，并额外提供 **CPU 峰值** 与 **内存峰值** 两列
- **按名称分组**：同名多实例进程合并为一行，显示合计资源占用（通过开关切换）
- **点击列头排序**：单击任意列即按该列**降序**排列（峰值优先），再次点击切换升序/降序，列头显示 ▲ / ▼ 方向指示
- **增量更新**：列表刷新时只更新既有行文字，不重建列表项，因此滚动条位置与选中状态保持稳定

### 占用曲线
- 右侧上下两块面积图：**CPU 占用历史** 与 **内存占用历史**
- 选中列表中的进程后，实时绘制该进程从本程序启动以来的占用变化
- 图表显示当前值、峰值与 Y 轴刻度

### 一键问豆包
- 选中进程后，点击底部状态栏右侧的「问豆包」按钮
- 自动查找并打开本机豆包桌面客户端，将选中进程的 CPU / 内存（含峰值）、实例数等信息整理成中文描述发送给豆包
- 让 AI 帮你判断该进程是否正常、是干什么的、是否建议处理

## 构建与运行

项目根目录提供编译与运行脚本。

### 一键构建（Debug + Release）
```bat
build.bat
```
会依次：
1. 编译 Debug 版本；
2. 发布单文件自包含 Release 版本到 `dist\`。

### 直接运行（推荐）
```bat
run-release.bat    # 运行 release 版（dist\SysResSpy.exe）
run-debug.bat      # 运行 debug 版
```

脚本会自动查找 exe 并启动，无需手动去目录翻找双击。

## 项目结构

```
d:\SysResSpy\
├── SysResSpy\               # 采样引擎（WinForms 版，UI 层在 UI\）
│   └── Sampling\
│       └── ProcessSampler.cs # 低开销采样核心（被 WinUI 版通过 link 复用）
├── SysResSpy.WinUI\         # WinUI 3 界面版
│   ├── App.xaml(.cs)
│   ├── MainWindow.xaml(.cs)  # 主窗口：列表 + 曲线 + 问豆包
│   ├── ProcessRow.cs         # 列表行模型（增量更新 + INotifyPropertyChanged）
│   ├── AreaChart.cs          # 面积图自绘控件（CPU / 内存）
│   ├── DoubaoHelper.cs       # 一键发送到豆包桌面客户端
│   └── Format.cs             # 字节/数值格式化
├── dist\SysResSpy.exe        # 发布的单文件 exe
├── build.bat                 # 构建脚本
├── run-release.bat           # 运行 release
└── run-debug.bat             # 运行 debug
```

### 采样引擎要点
- 采样核心（`ProcessSampler.cs`）与 UI 解耦，采到的历史数据放入环形缓冲（`ProcessHistory`）
- CPU 占用通过 `TotalProcessorTime` 差值计算；峰值在采样时同步维护（O(1)，不额外扫描）
- 设计目标即**极低系统占用**，保障监控工具本身不拖累性能
